    us in one run that the gate was sound and the defect was real state. A gate result you
    cannot reproduce alone is a clue, not a verdict.

    lines!) - noLoss contiguity is the assertion that catches the opposite failure.
  - Measure BOTH rects before touching a positioning rule: the 393px figure made the nav
    fix objective, and the same numbers became the regression assertion.
  - This directive's own tripwire list named a file that never existed
    (tools/verify-gantt-export.cjs). Rule 0.6 applies to the directive itself: correct the
    recorded location, do not trust the premise.

    pages load dist/, so build before measuring, every time.
