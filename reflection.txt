LESSONS (this session)
1. The P5.1 bug class: a dark-mode-scoped selector written as
   "body.dark-mode .a,.b{...}" scopes only .a - the comma leaks .b to every
   theme. When a shared class appears after a comma in a scoped rule, split
   the rule or fully qualify both. This one silently re-skinned every gold
   button on the marketing pages for weeks.
2. The P4.1 bug class: hiding a control with display:none inside a container
   that has no other content produces an "empty box" that reads as a broken
   feature. If a footer strip's only child is hidden, hide the strip too (or
   keep the child visible).
3. serve.cjs bakes CSP hashes at startup. After ANY inline-script edit the
   running dev server serves stale hashes and Chrome silently blocks every
   inline script (page renders, zero handlers). Symptom signature:
   document-level flags set by inline boot scripts are false. Restart the
   server by PID (wmic/Get-CimInstance to identify, taskkill //F //PID - never
   by image name).
4. The SW cache poisons itself from the HTTP cache: precache's cache.addAll
   does not bypass the HTTP cache, so a re-registered SW re-caches the stale
   asset it just fetched. When a fix "doesn't apply", check BOTH layers:
   unregister SW + delete caches, then reload, then verify the SW cache holds
   the new bytes.
5. A19 harness drift: qa-ai asserted the AI-WINDOW-DOUBLED-SIZE contract
   (>=1200px wide) but commit a5497ea had re-designed the window to a 420px
   right-docked sidebar without updating the gate. Height passed, width failed
   - a half-updated assertion pair, which is how drift hides. Fixed the
   harness to the docked contract per AGENTS.md CI rule 3 (app untouched;
   A/B verified via git history before touching anything).
6. Git-history -S searches are the fastest way to classify harness-failure vs
   app-regression: the CSS rule was byte-identical at HEAD, so the failure
   could not be this session's contamination.
