## Key Learnings

1. **Cloud card menu visibility**: The 3-dot menu pattern (opacity + pointer-events
   toggled by card hover) is a clean way to hide secondary actions while keeping
   them accessible. The delete option stays behind the trigger, never directly visible.

2. **Dark theme glass tuning**: Reducing glass-blur from 20px to 12px and glass-fill
   opacity from 0.08 to 0.05 makes the glass a subtle complement rather than
   overpowering. The key variables are --glass-blur, --glass-fill-dark, --glass-rim,
   --glass-border, and --glass-shadow.

3. **Carousel viewport restart**: IntersectionObserver is the correct pattern for
   restarting animations when elements scroll back into view. The existing
   visibilitychange handler covers tab switching but not scroll-away-and-back.

4. **CSS specificity for sign-in visibility**: The `display:none!important` rule
   for dormant sign-in buttons needed to be scoped more carefully — the field
   guide's `.site-signin.signin-trigger` should always be visible since it's a
   simple sidebar action, not a marketing CTA.
