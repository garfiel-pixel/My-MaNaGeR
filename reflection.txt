LESSON WORTH KEEPING
A schema behind the code is a live defect that no local gate can see. Every
green check in this repo runs against a local D1 that is always migrated to
head, so the one environment that mattered was the only one not measured. The
deploy recipe now refuses to ship when the remote migration list is not empty.
