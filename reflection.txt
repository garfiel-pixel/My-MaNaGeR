   b) CONFLICTING CLICK HANDLERS: admin.html had TWO document-level click
      listeners. The rail handler called `closeAdminNav()` for ANY click on a
      `[data-action]` inside `#app-sidebar`. The action map handler dispatched
      to `tglAdminNav()`. When clicking the close button, the first handler
      removed both classes, then the second toggled them back on.
   FIX:
   - Admin inline CSS changed to `body.admin-page.side-open`
   - `tglAdminNav()` simplified to toggle only `side-open`
   - `closeAdminNav()` simplified to remove only `side-open`
   - Rail click handler skips `.db-side-close` and `tglNav` actions

6. CSP HASH MANAGEMENT
   - The most common failure pattern: editing an inline <script> block in any
     HTML file changes its SHA-256 hash, which must be updated in BOTH
     worker.js INLINE_SCRIPT_HASHES and serve.cjs mirror. The hash is
     position-sensitive (must be in the same order as computed).
   - Also: serve.cjs must be RESTARTED after edits — a stale serve.cjs process
     serves old CSP headers, causing ALL inline scripts to be blocked with no
     visible error (functions become undefined).
