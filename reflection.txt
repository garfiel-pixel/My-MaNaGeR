Lessons learned:
- CSP hash computation must NOT use .trim() on inline script content -
  the browser hashes the raw bytes including whitespace
- Hash order in worker.js/serve.cjs must match the file-by-file extraction
  order in verify-csp-hashes.cjs (project->app->admin->dashboard->
  seed-test->field-guide->features.html) exactly, not just as a set
- serve.cjs needs full restart (kill old PID) after hash changes - the
  in-memory SPA server caches the CSP header
- Position:absolute buttons need distinct right/left offsets or they stack
- Grid search filtering is simplest done as a renderCards() filter step
