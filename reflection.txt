1. BUG HUNT (per owner request: audit, bring findings, fix the mention work + admin sidebar)
   Found 7 real bugs. Fixed 6; the last (C21 @mention keyboard-highlight CSS) was fixed
   as part of the mention batch. All fixes verified in-browser with headless Chrome.

   a. C21 @MENTION DROPDOWN DEAD ON ARRIVAL (HIGH) - the whole feature silently no-oped.
      renderTaskComments() wrote window._mentionStakeholders via a <script> inside an
      innerHTML string. Scripts injected via innerHTML never execute (HTML spec), and
      project.html's hash-only CSP would block them anyway. No other writer existed, so
      the dropdown never rendered. Fix: set window._mentionStakeholders directly in JS
      after el.innerHTML = html; (CSP-safe). Verified: typing "@Ma" shows the dropdown,
      ArrowDown highlights, Enter inserts the mention.
   b. MENTION KEYBOARD HIGHLIGHT INVALID CSS (MEDIUM): 'rgba(var(--gold-rgb,.08))' is
      invalid (--gold-rgb is already r,g,b so rgba() lost its alpha arg; browsers drop
      it). Fix: rgba(var(--gold-rgb), .08) - the repo's own established pattern.
   c. MENTION ITEM ESCAPING (LOW): names escaped only quotes, not < >. Fix: also escape
      < and >.
   d. ADMIN SIDEBAR NEVER SLIDES (owner-reported): clicking the hamburger only dimmed
      the screen (scrim) but the off-canvas panel never slid out; on desktop the rail
      was force-pinned so side-open had no visible effect. Fix: rewrote admin.html's
      sidebar CSS so the drawer slides on mobile (<=768px) and the rail pins + content
      shifts on desktop, with scrim, X close, and hamburger all wired and verified.
   e. CALCULATOR "Open" BUTTON DID NOTHING: toggleCalc flipped the FAB's visibility
      instead of opening/closing the panel. Fix in js/mmgr-calculator.js. Verified.
   f. ADMIN RAIL "CUSTOMIZE" ACCORDION DEAD: admin.html's data-rail-toggle button had

=== KEY LEARNING ===
1. innerHTML <script> never executes - a whole feature can silently no-op with no error.
   Grep for window.* writes and confirm real writers when a feature "does nothing".
2. rgba(var(--x-rgb, fallback)) needs the alpha OUTSIDE the parens: rgba(var(--x-rgb), .08).
3. Windows local wrangler dev: workerd crashes under full browser-page load; kill zombie
   workerd.exe PIDs by PID before restarts (they hold the port and hang every request);
   always --persist-to the harness default (os.tmpdir()/mmgr-wrangler-state) or phase2's
   direct D1/R2 reads fail; apply D1 migrations to a fresh persist dir BEFORE boot or
   every cloud API 500s with "no such table".
4. Every inline-script edit in a page with CSP needs hash regen in BOTH worker.js and
   serve.cjs - use tools/regen-csp-hashes.cjs and verify.
5. Do not restart wrangler while zombie instances hold the port - netstat may show
   LISTENING from a dead PID; requests hang in CLOSE_WAIT forever.
