         Deployment Guide
      

      

        
Publishing changes: edits here save to this browser only.
        To make them visible to your visitors, click Download Static Manifest, then commit the resulting
        projects-data.js to your repository and deploy via
        npx wrangler deploy (Cloudflare Workers static assets). For cloud-linked projects, the per-row
        Update Cloud Snapshot button pushes the project's latest state straight to the cloud backend
        instead, no file involved.

        
Security model (local-first):
        Everything stays on this device: admin password hash, session flag, and plaintext access codes live in
        localStorage/sessionStorage only. The published projects-data.js contains
        SHA-256 hashes only. Google sign-in is optional. Drive backup/restore are explicit opt-in actions.
