## Key Learnings

1. **AI overlay → sidebar conversion**: The full-screen backdrop (`position:fixed;inset:0;
   background:rgba(...)`) pattern converts cleanly to a fixed sidebar by changing to
   `top:var(--hdr-h);right:0;bottom:0;width:420px` and removing the backdrop layer.
   The `open()`/`close()` functions in mmgr-ai.js only toggle a class, so no JS changes
   were needed for the open/close mechanism.

2. **CSP hash order matters**: The verify script scans files in a specific order (project.html
   first, then app.html, then admin.html, then standalone files). Hashes MUST be in that
   order in `INLINE_SCRIPT_HASHES`. Getting the count right (17) is necessary but not
   sufficient — the ORDER must match too.

3. **Toggle pattern**: A proper toggle needs bidirectional state (read current + set next),
   not just one-way. The old "Hide demos" was fire-and-forget; the fix reads the current
   localStorage value and flips it, updating the label and icon accordingly.
